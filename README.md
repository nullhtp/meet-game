# Поближе 🎴

PWA-игра с карточками-вопросами, чтобы компания малознакомых взрослых могла узнать друг друга ближе.

## Что внутри
- **~55 вопросов** в 5 категориях: 🎈 Знакомство, 🔥 Поглубже, 💭 Что если, 😄 Весёлое, ❤️ Ценности.
- **Свайпы карточек** (палец / мышь) + кнопки «вперёд / назад / перемешать».
- **Режим «по очереди»** — добавь имена игроков, и приложение само показывает, чей ход.
- **Фильтр по категориям** — начните с лёгких вопросов, потом уходите вглубь.
- **Работает офлайн** и **ставится на телефон** как обычное приложение (PWA).
- Прогресс, выбранные категории и игроки сохраняются между запусками.

## Как запустить
PWA требует HTTP(S) — просто открыть файл `index.html` двойным кликом не даст офлайн-режима и установки. Поднимите локальный сервер из папки проекта:

```bash
# любой из вариантов
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте `http://localhost:8000` в браузере телефона или компьютера.

## Как установить на телефон
- **iPhone (Safari):** Поделиться → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

После установки игра работает без интернета.

## Как играть
1. Соберитесь компанией, положите телефон в центр (или передавайте по кругу).
2. По желанию в ⚙️ добавьте имена — тогда приложение подскажет, чей ход.
3. Читаете вопрос вслух, отвечаете, смахиваете карточку или жмёте → за следующим.
4. Хотите глубже — оставьте только категории 🔥 и ❤️.

## Файлы
- `index.html` — вся игра (разметка, стили, логика, вопросы).
- `manifest.json` — описание PWA.
- `sw.js` — service worker для офлайн-режима.
- `icon.svg` — иконка приложения.
